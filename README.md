# Cake Palace - Premium Cake Shop Website

## Project Overview
Cake Palace is a responsive cake shop website developed using HTML, CSS and JavaScript.

## Features
- Premium homepage design
- Cake gallery with category filters
- Shopping cart with quantity controls
- Total price calculation
- Custom cake enquiry form
- Responsive design for desktop and mobile

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git and GitHub
- Jenkins

## Version History

### Version 1.0
- Created the cake shop website.
- Added homepage and cake gallery.

### Version 1.1
- Added cake category filters and shopping cart.
- Improved responsive styling.

### Version 1.2
- Added Jenkins pipeline for automated validation.

## How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.

## Note
This is an academic demonstration project. The enquiry form does not save orders to a server or process payments.
